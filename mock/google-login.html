Google OAuth 테스트 콘솔

AIdeep 백엔드의 Google OAuth 흐름(로그인 · 회원가입 완료 · 연동 · 해제 · 비밀번호 · 세션)을 한 페이지에서 검증합니다.

0. 공통 설정

값은 localStorage 에 자동 저장됩니다.

1. Google 로그인 / 가입 개시 public

GET /auth/google 로 이동합니다. Google 인증 후 callback 이 JSON 을 반환하므로, 그 JSON 을 아래 “2. 콜백 응답 붙여넣기” 에 붙여넣으면 자동으로 토큰/티켓을 추출해 채워줍니다.

2. 콜백 응답 붙여넣기

Google 로그인 / 연동 완료 후 백엔드가 보여준 JSON 전체를 그대로 붙여넣고 “파싱” 을 누르세요.
- kind: "login" → accessToken / refreshToken 자동 채움
- kind: "signup_required" → ticket 자동 채움 (아래 3번 사용)
- kind: "linked" → 연동 완료 (아래 5번에서 목록 확인)

3. OAuth 회원가입 완료 public

POST /auth/oauth/signup/complete — signup_required 응답의 ticket 으로 회원가입을 마무리합니다.

필수: true

4. 세션 관리 accessToken / refreshToken

내 정보: GET /user/me · Refresh: POST /auth/refresh · Logout: DELETE /auth/logout

5. OAuth 연동 관리 accessToken 필요

목록: GET /auth/oauth/links · 해제: DELETE /auth/oauth/link/:provider

Google 연동 시작 (Bearer 필요 + redirect)

GET /auth/oauth/link/google 는 JwtAuthGuard + 302 redirect 이므로 단순 브라우저 네비게이션으로는 Authorization 헤더를 실을 수 없습니다. 다음 중 하나로 테스트하세요:

  1. 아래 curl 명령을 복사·실행하고 응답의 Location 헤더(=Google URL) 를 브라우저 주소창에 직접 붙여 넣어 진행합니다.
  2. 또는 Swagger /docs 에서 “Authorize” 로 accessToken 입력 후 /auth/oauth/link/google 의 “Try it out” 실행 → 응답 헤더의 Location URL 을 브라우저에서 엽니다.

6. 비밀번호 설정/변경 accessToken 필요

PATCH /auth/password — 비밀번호 미설정 계정(OAuth 가입자)은 currentPassword 생략 가능, 이미 설정된 경우 필수.
